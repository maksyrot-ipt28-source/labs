Лабораторна робота №4
Тема: Візуалізація даних 2.
Виконав: Сиротін Максим, ФБ-42

Опис завдання
Створення програми з інтерактивним інтерфейсом для малювання графіка функції гармоніки ($y(t)=A^{*}\sin(\omega t+\varphi)$) з накладеним шумом. 
Реалізовано:
Можливість змінювати параметри гармоніки (амплітуда, частота, фаза) та шуму (середнє значення, дисперсія) за допомогою інтерактивних слайдерів.
Фільтрацію зашумленої гармоніки за допомогою IIR-фільтра низьких частот.
Візуальне порівняння початкової (чистої), зашумленої та відфільтрованої гармонік.
Елементи керування: чекбокс для увімкнення/вимкнення шуму та кнопка скидання параметрів.

Вимоги до системи
ОС: Windows / Linux / macOS
