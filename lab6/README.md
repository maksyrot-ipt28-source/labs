# Lab 6: C++ OpenCV Video Processor

Виконав: Сиротін Максим ФБ-42
Дисципліна: ЗПАД

## Опис завдання
Створення модульної С++ програми з використанням бібліотеки OpenCV, яка читає відеопотік, відображає його у вікні та вмикає різні режими обробки зображень (Інверсія, Blur, Canny, Sobel) в залежності від натиснутих клавіш.

## Вимоги до ОС та компілятора
- OS: Linux (Ubuntu / Kali Linux)
- CMake: 3.10 або вище
- Compiler: GCC/G++
- Library: OpenCV

## Інструкція налаштування і запуску
1. Встановлення залежностей (виконати один раз):
   ./preinstall.sh

2. Компіляція проєкту:
   ./build.sh

3. Запуск готового бінарного файлу:
   ./run.sh

## Керування програмою
- `o` - Оригінальне відео
- `i` - Інверсія кольорів (bitwise_not)
- `b` - Gaussian blur
- `c` - Canny фільтр
- `s` - Фільтр Собеля
- `q` або `ESC` - Вихід з програми
