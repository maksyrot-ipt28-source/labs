Опис завдання
Створення інтерактивного веб-додатка за допомогою бібліотеки Streamlit для візуалізації та аналізу вегетаційних індексів (VCI, TCI, VHI). Реалізовано вибір показника, області, часових інтервалів (роки та тижні), а також сортування даних та побудову порівняльних графіків.

Вимоги до середовища
Встановлений інтерпретатор Python
Встановлені пакети з файлу `requirements.txt`

Інструкція з налаштування та запуску
1.Переконайтеся, що ви знаходитесь у віртуальному середовищі `venv`
2.Встановіть необхідні залежності
   pip install -r requirements.txt
