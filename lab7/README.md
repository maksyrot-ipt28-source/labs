Опис роботи
Мета: освоєння роботи з cv::dnn для детекції облич на базі нейронної мережі ResNet-10. 
Програма дозволяє виконувати детекцію облич у режимі реального часу або на відеофайлі.

Архітектура
- CameraProvider: клас для захоплення відеопотоку.
- KeyProcessor: обробляє клавіатурне введення та перемикає режими обробки (включаючи FACE).
- FrameProcessor: реалізує логіку детекції облич за допомогою cv::dnn::readNetFromCaffe.
- Display: виводить оброблений кадр на екран.

Вимоги до системи
- ОС: Linux Ubuntu
- Компілятор: GCC 11+
- Система збірки: CMake 3.20+
- Бібліотеки: OpenCV 4.x

Інструкція зі збірки та запуску
1. Встановлення залежностей:
   ./preinstall.sh

2. Збірка проєкту:
   ./build.sh

3. Запуск програми:
   ./run.sh
